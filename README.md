# Assignment 6. jQuery (Selectors, Effects, Animations)

**Student:** Zhibek Kypshak
**Group:** SE-2528

## Description
Multi-page website demonstrating jQuery basics. A navbar on every page links to all parts of the assignment.

## Pages
- `index.html` - Part 1: setup, selectors, `.text()`, `.html()`, `.css()`
- `effects.html` - Part 2: hide/show/toggle, fade, slide
- `dom.html` - Part 3: append/prepend/remove, attributes, live form input
- `animations.html` - Part 4: `.animate()`, sequential and combined animations
- `project.html` - Part 5: accordion menu mini project

## Project structure
- `js/` - JavaScript files for each part (`part1.js` - `part5.js`)
- `style.css` - shared styles

## How to run
1. Clone the repository.
2. Open `index.html` in a browser (internet is required for the jQuery CDN).
3. Use the navbar to move between parts.
