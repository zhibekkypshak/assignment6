Task 11. Mini Project: Accordion Menu

What is jQuery?
jQuery is a JavaScript library that simplifies DOM manipulation, events and animations.
What are selectors?
Selectors let you find elements by ID, class, tag or attribute, e.g. $("#id"), $(".class"), $("p").
What are effects?
Effects such as hide, show, fade and slide make pages interactive and dynamic.
What is animate()?
The .animate() method creates custom animations of numeric CSS properties.
